# WebCrawler

WebCrawler is a powerful tool designed to analyze and visualize the internal linking structure of websites. It provides comprehensive reports on how pages are interconnected, making it an essential tool for SEO specialists, webmasters, and digital marketers looking to optimize their website's architecture and improve search engine visibility.

## Live Demo

Check out the live demo of WebCrawler: [https://web-crawler-kappa.vercel.app/](https://web-crawler-kappa.vercel.app/)


## The Problem We Solve

Understanding a website's internal linking structure is crucial for:
- Improving search engine rankings
- Enhancing website navigation
- Identifying orphaned pages
- Optimizing crawl budget
- Enhancing user experience

Manually mapping these connections is time-consuming and error-prone. WebCrawler automates this process, delivering accurate, actionable insights in seconds.

## Features

- **Comprehensive Link Analysis**: Map all internal links within a website
- **Visual Representation**: Easy-to-understand visualization of page relationships
- **SEO Optimization**: Discover opportunities to improve internal linking for better SEO
- **User-Friendly Interface**: Intuitive dashboard for analyzing and interpreting results

## Getting Started

### Prerequisites
- Node.js (v14 or later)
- npm (v6 or later)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/WebCrawler.git
   cd WebCrawler
   ```

2. **Install dependencies**
   ```bash
   # Install server dependencies
   npm install
   
   # Install client dependencies
   cd WebCrawler
   npm install
   ```

### Running the Application

1. **Start the backend server**
   ```bash
   npm start
   ```

2. **In a new terminal, start the frontend development server**
   ```bash
   cd WebCrawler
   npm run dev
   ```

3. **Access the application**
   Open your browser and navigate to [http://localhost:3000](http://localhost:3000)

## 🛠️ Technologies Used

## 📊 Example Usage

1. Enter the target website URL in the input field
